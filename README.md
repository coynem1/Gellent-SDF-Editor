# What is Gellent?
Gellent is an art application for 2D SDFs. Art from this app is entirely user generated content, where any created models can be exported as images or can be viewed and edited through this app. This application is used for creating and exporting models, for quick prototypes or full scenes that can be used for concept art, illustrations or even environment design. 

The rendering for these models uses the GPU, to speed up the memory hungry SDF graphics process. This project features implementing complex rendering algorithms and has lots of room for expansion. SDF’s are a whole branch of computer graphics rendering that is on a completely new software frontier that deserves more attention. The end goal has been to make a fun, easy to understand art tool with plenty of shortcuts and user customization. All of the functionality is entirely encapsulated inside the modelling application.

# Install and run
If you are using Windows, you can immediately try it out by downloading the latest executable under `Releases`. This hasn't been tested on any other OS, but you can try by manually downloading and running it, following the next section.

# Running Gellent manually
This project runs using Java 25, if you already have Java installed, you can skip this first step:
- Install the correct version depending on your operating system from https://www.oracle.com/java/technologies/javase/jdk25-archive-downloads.html
- Choose an IDE to run this project on, such as IntelliJ and select Gradle build tool to manage the packages that need to be downloaded.
- Run the `/src/main/java/main.java` file.
